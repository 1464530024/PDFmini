# PDFmini 使用说明

> 轻量 · 极速 · 极简 —— 专注 PDF 阅读与编辑的桌面工具
>
> 版本：v1.3.7

---

## 一、软件简介

PDFmini 是一款面向 Windows 的轻量级 PDF 阅读与编辑工具。保留日常最常用的阅读、查找、批注、文字与图片编辑、页面整理、**Word 转 PDF** 等核心能力，移除了 OCR、数字签名、云端 AI、打印、主题切换等模块，因此：

- **体积小**：安装包约 69.6 MB、安装后约 217 MB（原版 PDFgear 为 379 MB）
- **打开快**：148 页文档约 0.6 秒完成解析并立即显示首屏（无需等待全部页面加载）
- **无卡顿**：单进程架构，无后台网络请求、无订阅/评分/更新检查
- **多文档**：底部标签条可同时打开多个 PDF 并自由切换
- **中英文界面**：安装时可选择语言，软件内也可随时切换

## 三、安装与卸载

### 安装
1. 双击 `PDFmini-Setup-1.3.1-x64.exe`
2. **选择安装语言**（简体中文 / English）—— 安装时的语言会成为软件首次启动的界面语言
3. 选择安装位置（默认安装到当前用户目录，无需管理员权限）
4. 可选择是否创建桌面快捷方式
5. 点击「安装」，完成后自动启动

> 安装语言也可以在软件里随时切换：**更多 → 界面语言 → 中文 / 英文**（切换后立即生效并记住）。

### 卸载
任选其一：
- **开始菜单** → 找到 PDFmini → 右键 → 卸载
- **控制面板 → 程序和功能** → 选择 `PDFmini` → 卸载
- 安装目录下的 `Uninstall PDFmini.exe`

卸载会同时清除程序文件与个人配置数据（最近打开记录、界面设置）。

## 五、两种模式

打开 PDF 后默认进入 **浏览模式**（只读，防止误改）。需要修改内容时，点击左上角 **「编辑」** 切换到编辑模式。

| 模式 | 分组 | 功能 |
|---|---|---|
| **浏览** | 视图 | 侧栏、缩小／缩放／放大、适应宽度、适应页面、旋转视图、全屏 |
| | 导航 | 首页、上一页、下一页、末页、查找 |
| **编辑** | 文字与图片 | 插入文字（4 种字体 / 字号 / 颜色）、添加图片、框选删除、链接、图章、签名 |
| | 批注 | 高亮、下划线、删除线、文本框、便签、墨迹、形状、橡皮擦 |
| | 页面 | 页面管理、插入空白页、从文件插入、合并 PDF、拆分 PDF、裁剪页面 |
| | 工具 | 水印、页眉页脚、页码、填写表单、导出文本、导出图片、清除批注 |

功能栏右侧常驻按钮（名称常显）：**打开 / 保存 / 撤销 / 重做 / 关闭 / 更多**（更多内含另存为、还原到打开时、导入图片 / Word、页面管理、界面语言、使用说明、关于）。

## 六、文字与图片编辑

> **本版起不再需要「编辑文字 / 编辑图片」按钮**：只要在**编辑模式**下，直接点页面上的内容即可。

### 点文字即编辑（原「编辑文字」）

> v1.3.5 修复：以前点开一行文字、**什么都没改**就点保存，提交后文字会莫名分成两行；现在提交时会按实际渲染宽度重新量一次文本框，单行文字永远保持单行。

1. 切换到「编辑」模式（左上角 **「编辑」**）
2. **鼠标移到文字上**，该行会浮出一层淡红提示，光标变成 **I 形文本光标**（表示这里可以点）
3. **点一下** → 该行文字立刻变成白底可编辑文本框，自动填入这一行的完整原文，**光标落在你点击的那个字符位置**
4. 直接**增删/替换文字**：Backspace 删除、直接打字插入、`Ctrl+A` 全选后重输、`Ctrl+V` 粘贴
5. **点任意空白位置即自动保存**（也可以按 `Enter` 或 `Esc`）

> 要点：
> - **可以连续编辑任意多行**：点完第一行再点第二行、第三行……前面的修改都会自动保存下来。
> - **把一行文字删空 = 删除这段文字**：白底遮盖会保留，不会再留下一个空的文本框；之后**再点同一位置也不会把原文又调出来**。想恢复用 `Ctrl+Z`。
> - **是「原地替换」，不是「新增文字」**——文本框与原文位置、字号一一对齐，覆盖框精确盖住原文字。
> - 自动识别**整行/整块文字**（PDF 里一行常被拆成多个碎片，本软件会按字符位置去重后还原完整文字，并按横向间隔自动分块）。
> - 中文输入法组词时按 `Enter` 是确认候选词，不会误结束编辑。
> - 想移动整块文字，请把内容删空后用「插入文字」在目标位置重写。

> 原理说明：PDF 内容流不可直接改写，因此采用「覆盖原文字 + 写入新文字」的通用做法。原文字仍在文件中，但显示为被覆盖后的新文字。

### 插入文字（新增文字，支持 4 种字体 / 字号 / 颜色）

点击 **插入文字** → 在页面任意位置点击，即出现一个虚线文本框，旁边会自动弹出**浮动工具条**：

```
[字体 黑体 楷体 仿宋 等宽]  [字号 A- 14 A+]  [颜色 ●●●●●●●●]  [完成]
```

- **4 种字体**：黑体、楷体、仿宋、等宽 —— 屏幕预览与写入 PDF 的字形一致（中文按需子集内嵌，不增加安装体积）
- **字号**：`A-` / `A+` 逐档调整
- **颜色**：8 种常用颜色的色点，点一下立即生效
- 输入完成后点 **完成**、或点页面**空白处**即保存

> 说明：
> - 工具条上的设置**只作用于当前这个文本框**；想改「新建文本框的默认字体/字号/颜色」，在功能栏 **右键「插入文字」按钮**（或按住 `Shift` 点它）即可设置默认值。
> - **不会再出现多余的细窄小框**：一次性只服务一个文本框，点空白保存后不会顺手再建一个空框；空文本框会显示灰色占位「输入文字…」。
> - 保存后的文本框可以**直接拖动移动**；点它会选中（出现四角手柄与「修改文字 / 删除」按钮），在「对象框上方的操作按钮」里可再次进入文字编辑。
> - 多行输入用 `Shift + Enter`；普通 `Enter` 结束编辑。

### 框选删除（文字 / 图片 / 图形一起删）

**操作方式**：编辑模式下，**按住鼠标右键在页面上拖出一个方框**，松开后页面出现虚线选区和一个浮动工具条：

```
[已框选]  [删除]  [取消]
```

- 点 **删除** 才真正删除（点 **取消** / 点别处 / 按 `Esc` 都只是取消本次框选）
- 也可直接用键盘 `Delete` 确认删除
- 也可以点功能栏 **框选删除** 按钮后，用**左键**拖框（方便触控板用户）

**左键不会被框选占用**：编辑模式下**按住左键拖动 = 平移页面**（和普通 PDF 阅读器一致）；左键单击文字/图片仍然是就地编辑。

**为什么删得干净**：删除时除了处理文字块与图片对象，还会对框内**渲染出来的像素**做一次连通域分析，把每一团墨迹都盖掉 —— 所以矢量化图形（例如二维码、图表底纹、扫描件里的点阵）也能删干净，不会残留零散黑块。

- 判断规则：内容中心落在框内、或与框的重叠面积超过约 1/3，即视为被框住
- 文本、PDF 原生图片、矢量图形、以及你自己插入的文字 / 图片对象都可以被框选删除
- 删除后 `Ctrl+Z` 可一次撤销

> 提示：编辑模式下「左键点文字 = 编辑文字」「左键点图片 = 编辑图片」「左键拖 = 平移页面」「右键拖 = 框选删除」，四种操作自动区分，无需切换工具。

### 添加图片（三种方式）
1. **按钮**：编辑模式 → **添加图片** → 直接弹出文件夹选择图片（可多选），图片插入当前页中央
2. **粘贴**：复制任意图片后按 `Ctrl+V`，图片插入当前页中央
3. **拖拽**：把图片文件直接拖到页面上，图片落在鼠标松开的位置

插入后的图片会**自动进入编辑状态**，可立即调整：
- **拖动**移动位置（实时跟手，无卡顿）
- 拖动四角小方块 **缩放**（默认锁定长宽比，按住 `Shift` 自由拉伸；对角固定，只改变拖动的一边）
- 对象框上方有 **替换图片** 与 **删除** 按钮
- 按 `Delete` 删除，`Ctrl+Z` 撤销

> 若拖拽/粘贴图片时当前是「浏览」模式，软件会自动切换到「编辑」模式，无需手动切换。

### 编辑状态与「完成」按钮（重点）

选中对象后，对象框**右下角外侧会出现一个红色「完成」按钮**。

**编辑期间可以反复操作，不会一次就被打断：**

1. 拖动 → 松手 → 仍是编辑状态 → 继续拖动
2. 缩放 → 松手 → 仍是编辑状态 → 继续缩放
3. 交替缩放、移动任意多次，直到满意
4. 点击 **「完成」**（或按 `Enter` / `Esc`，或点击页面空白处）才结束编辑

> 也就是说：**一次选中 → 多次调整 → 点「完成」**。中途松手不会退出编辑状态。

### 点图片即编辑（原「编辑图片」）

编辑模式下**直接点击 PDF 里原本就有的图片**即可选中它（无需先点任何按钮），选中后出现四角手柄与操作按钮，支持：

- **拖动移动** —— 在原位置留下白底遮盖、把图片内容搬到新位置（效果等同「把这张图挪了个位置」）；遮盖层绘制在所有对象**下方**，因此**不会遮挡图片的选中边框与缩放手柄**
- 四角 **缩放**（默认锁定长宽比，按住 `Shift` 自由拉伸）
- ⟳ **替换图片** —— 换成你自己的图片，位置与宽度不变
- ✕ **删除**（对象框右上角）
  - 选中的是 **PDF 里原本就有的图片** → **白底抹除**（原图位置变成白块，保存后也不会再出现）
  - 选中的是 **你自己插入的图片** → 直接移除（原图不受影响）
  - 两种情况都可以 `Ctrl+Z` 撤销

**两种方式都能结束编辑（保存）：**

1. 点击页面**任意空白位置** —— 自动保存
2. 点击对象框右下角的红色 **「完成」** 按钮

> - **先点一下选中图片，再拖动它**即可移动（直接按住图片拖会变成「框选删除」，想直接拖动图片请先点一下选中）。
> - 已经被接管的原生图不会再次被拾取，因此**反复点空白区域也不会复制出多余的图片**。

### 对象通用操作
点击任意批注／图片／文字框即可选中，出现红色边框、四角缩放手柄、对象框上方的操作按钮，以及右下角的「完成」按钮。

## 六之二、链接

在 PDF 上加可点击的链接（写入的是标准 PDF `/Link` 注解，保存后永久生效，用其他 PDF 阅读器打开同样可点）。

**方式一：拖拽划出区域**
1. 编辑模式 → **链接**
2. 在页面上拖拽划出链接区域，松开后弹出对话框
3. 填写网址（需以 `http://` 或 `https://` 开头），或填写要跳转的页码
4. 点击「创建链接」

**方式二：菜单快速添加**
点击 **链接 ▾** →
- **网页链接…**：在当前页中央创建链接框并填写网址
- **跳转到指定页…**：创建文档内跳转链接（填写目标页码，链接区域可拖动到任意位置覆盖标题/目录项）

**使用链接**
- 切回 **浏览模式**，点击链接区域即可用系统默认浏览器打开网址，或跳转到指定页
- 编辑模式下：第一次点击选中（可移动／缩放／修改／删除），再次点击同一链接则直接打开
- 选中链接后，对象框上方会出现 **✎ 修改链接** 按钮，可改网址或目标页码

## 六之三、导入与 Word 转 PDF

### 统一导入入口
首页点击 **导入图片 / Word**（或功能栏「更多 → 导入图片 / Word…」），在弹出的文件选择框里可以**多选**图片与 Word 文档：

| 选择的文件 | 软件行为 |
|---|---|
| 图片（png / jpg / jpeg / gif / bmp / webp） | 自动执行**图片转 PDF**（每张图一页，尺寸与原图一致） |
| Word 文档（.docx） | 自动执行**Word 转 PDF**，完成后作为新文档打开 |

### 拖拽导入
把文件直接拖到窗口上：

- **PDF** → 直接打开
- **图片** → 若拖到某一页上则插入到该位置；拖到页面外（或没有打开文档）则转为新的 PDF
- **Word(.docx)** → 转为 PDF 并作为新文档打开

### Word 转 PDF 的实现与范围
内置解析 `.docx`（Office Open XML），**完全离线、不依赖 Office / WPS / LibreOffice，也不增加安装体积**。可以还原：

- 标题层级（Title / Heading 1–4）与正文段落
- 项目符号列表、编号列表（按 • 呈现）
- 表格（自动分列、自动换行、绘制边框）
- 中文与英文混排、按页面宽度自动折行、超出一页自动分页
- 中文字体自动内嵌系统黑体子集

暂不还原：浮动图片、艺术字、分栏、页眉页脚域、批注与修订标记、精确的行距与缩进。仅支持 `.docx`（不支持旧版 `.doc`）。

## 六之三之二、文字缺失修复（遇到“缺字”时用）

少数 PDF（多是某些 HTML/网页导出工具生成的）字体结构异常：**每个字形用一个独立的 Type3 字体**，还把部分字符的编码表写坏了。这类文件在 pdf.js 里会出现：

- 标题/整行文字**画不出来**（原位置一片空白）
- 个别字显示成 **□（空心方块）**
- 复制、搜索、导出得到的文字是 **错字**（例如「大」变成「⼤」这种康熙部首）

PDFmini 内置三层处理，默认开启：

| 处理 | 说明 |
|---|---|
| **缺字补画** | 渲染完成后逐字检查「这个位置是不是根本没画出东西」，是的话用系统字体把该字补上，整行/整字缺失都能救回来 |
| **编码还原** | 把文本层里的康熙部首（U+2F00–U+2FD5）与兼容汉字还原成规范汉字，使复制、搜索、导出、以及**保存回 PDF 的文字**都正确 |
| **搜索/导出统一** | 全文查找、导出文本同样使用还原后的文字，避免“明明有这几个字却搜不到” |

开关位置：**更多 → 文字缺失修复**（勾选=开启，默认开启）。关掉后按 pdf.js 原始结果渲染。

> 说明：如果某个字在 PDF 里连**编码**都是坏的（生成器写成了空字符），任何渲染器都只能显示成方块；这类字目前无法自动还原。

## 六之四、界面语言（中英文切换）

三种方式确定语言：

1. **安装时选择**：安装包第一步会提供「简体中文 / English」选择，选择结果写入安装目录，软件首次启动即使用该语言。
2. **软件内切换**：功能栏 **更多 → 界面语言 → 中文 / 英文**，切换后界面文案立即刷新并记住（写入用户配置）。
3. **未做任何选择时**：跟随系统语言（中文系统用中文，其它用英文）。

> 切换语言只影响界面文案，不会修改文档内容，也不会重新打开文档。

## 七、其它功能

### 阅读
打开本地 PDF、拖拽打开、最近记录、缩略图导航、书签目录、全文查找（命中高亮 + 结果列表直达）。

### 浏览模式下选中 / 复制（v1.3.7 重构）

浏览模式是只读的，专门用来「看 + 拿」：

| 想做什么 | 怎么做 |
|---|---|
| 复制一段文字 | **按住鼠标左键在文字上拖拽**即可选中（选区显示为**统一的浅蓝色**），按 `Ctrl+C` 复制 |
| 复制整页文字 | **在页面上右键 → 复制本页文字** |
| 复制某张图片 | **左键单击图片**（出现蓝色选中框）→ 按 `Ctrl+C`；或 **在图片上右键 → 复制此图片** |
| 复制整页为图片 | **在页面上右键 → 复制本页为图片**（按 2× 分辨率截图，可粘贴到聊天/文档里） |
| 复制选中的文字 | 右键 → **复制选中文字**（选区还在时） |

> **选中高亮是自绘的**：每行一条**等高、等左边界**的浅蓝色条，覆盖范围精确到字。
>
> 为什么不用浏览器原生高亮？原生 `::selection` 是按「字形盒」逐块画的：
> - 一行里中文和网址的字号不同，块高就差几像素 → 同一条视觉行被切成高低两块；
> - 相邻块半透明叠加处颜色变深 → 「颜色重叠、不统一」；
> - 字体被拆成「一字一块」的 PDF 会画出上百个碎块 → 阶梯状；
> - 高亮画的是「字体盒」（比行盒还高十几个像素）→ 视觉上越到邻行。
>
> 本版把整套逻辑重写了，分两层：
> 1. **行模型**：把文本层所有字块归成「视觉行」，每行算出一个固定的行带（行心 + 字高中位数）。行带只跟页面尺寸有关、**与当前选区无关**，所以高亮条永远落在同一位置，拖选时不会上下跳。
> 2. **选区映射**：由选区求出每个字块被选中的「字符区间」，按字符比例换算横坐标 —— 覆盖到哪就是哪，不会缺一段、也不用整行凑数（原「选中不全」已修）。
>
> 另外两处：
> - **缩放 / 旋转**：缩放前把选区记下来（按「第几个字块 + 第几个字符」），等页面按新尺寸重排完成后原样接回来，并按新的字号重算高亮 —— 缩放后选区还在、位置正确，不会再出现按旧比例画出的错位高亮。
> - **拖选顺序**：有些 PDF 的文字层 DOM 顺序与视觉顺序不一致（鼠标在第 3 行、高亮却跳到第 5 行）。现在渲染完会把字块按视觉顺序重排一次（绝对定位元素，重排不影响显示），拖选顺序与复制出的文字顺序都随之正确。
>
> 其余：
> - 图片是 PDF 里的原生图片，会按原始清晰度（2.5× 重采样）裁出来，不是屏幕截图。
> - 编辑模式下文字不可拖选（避免和「点文字就地编辑 / 左键拖动平移页面」打架），需要复制文字请切回 **浏览**。

## 十、常见问题

**Q：为什么打开某些 PDF 后文字显示不全？**
A：为提升渲染速度，本软件关闭了系统字体匹配。若 PDF 未内嵌字体，个别字符可能显示异常，但复制与导出文本不受影响。

**Q：编辑文字后原文字还在吗？**
A：在。PDF 无法真正改写已有文字，本软件用白色底框覆盖原文字再写入新文字。

**Q：保存后能撤销吗？**
A：批注与编辑内容在「保存 / 页面操作」时写入 PDF。写入后需用其它工具处理，建议保留原始文件副本。

**Q：支持 OCR 识别扫描件、格式转换、打印吗？**
A：均不支持，这是有意精简（原版 OCR 占 267 MB）。如需这些功能请使用专用工具。

**Q：没有网络能用吗？**
A：完全可以。软件全程无网络请求。

## 十二、已知限制

1. 旋转为「视图旋转」，不写入文件；需要永久旋转请使用「页面管理」中的左转/右转。
2. 视图处于旋转状态时无法新增编辑内容（请先复位旋转）。
3. 「点文字即编辑」为覆盖式编辑，不修改原始文字对象。
4. 批注与编辑内容在保存时写入内容流，保存后不可再单独编辑。
5. 链接会写入标准 PDF `/Link` 注解（网页链接为 URI 动作，页内跳转为 GoTo 动作）。
6. 文字 / 图片编辑与「框选删除」均采用「白底遮盖 + 覆盖式重写」实现：能修改、移动、替换、抹除，但不会改写 PDF 原始内容流（保存后可用其它工具再次处理）。
7. 文字识别依赖页面已渲染出的文字层：文档首次打开时只渲染可视页面，滚动到还未渲染的页面后会自动补上；因此滚动到未渲染页面后请稍等片刻再点击文字。
8. 页面管理缩略图最多显示前 300 页，操作仍对全部页面有效。
9. 图标为占位版本，替换 `build/icon.ico` 后重新打包即可更换。
10. 「文字缺失修复」对个别字体结构异常的 PDF 做了补画；若发现个别字补得位置略偏或颜色不符，可在「更多 → 文字缺失修复」中关闭。
11. Word 转 PDF 为内置轻量排版引擎，复杂版式（浮动图片、艺术字、分栏等）会有损失；仅支持 `.docx`。
12. 「框选删除 / 删除文字」采用像素级白底遮盖，删除后原文仍在 PDF 内容流中（只是被盖住）；如需彻底移除，请用其它工具处理原始内容流。
13. 为精简体积，打包时**已移除 Electron 运行时中的 `LICENSES.chromium.html`**（Chromium/Electron 的开源许可文本，不经程序读取，也不影响任何功能）；若需对外分发，请自行补充相应许可声明。如需保留该文件，删除 `scripts/after-pack.js` 中 `STRIP_FILES` 的对应项即可。

## 十三、从源码构建

```bash
npm install              # 安装依赖
npm run dev              # 开发模式运行（带开发者工具）
npm run build:renderer   # 仅构建渲染进程
npm run dist             # 打包生成安装包（输出到 dist/）
npm run smoke            # 跑完整套自检（20 个用例，一次启动 Electron 跑完）
npm run smoke -- sel     # 只跑名字里含 sel 的用例；-- --list 可看全部用例名
```

目录结构：

```
PDFmini/
├─ src/main/          # Electron 主进程（窗口、IPC、文件读写、关闭拦截）
├─ src/renderer/      # 界面（HTML/CSS/JS：pdf.js + pdf-lib）
│  └─ js/
│     ├─ app.js       # 入口：工具栏、对话框、快捷键
│     ├─ tabs.js      # 多文档会话管理
│     ├─ viewer.js    # 渲染核心（惰性解析、虚拟化渲染）
│     ├─ annotate.js  # 批注与编辑层
│     ├─ flatten.js   # 批注写入 PDF
│     ├─ ops.js       # 页面操作、水印、表单
│     ├─ io.js        # 打开/保存/导出/拖拽/导入
│     ├─ docx.js      # Word(.docx) → PDF 离线转换
│     ├─ i18n.js      # 中英文文案与语言切换
│     └─ sidebar.js   # 缩略图、书签、搜索
├─ installer/lang.nsh # 安装器扩展：把所选语言写入 lang.txt
├─ scripts/
│  ├─ build.js            # esbuild 打包脚本（含体积优化）
│  ├─ after-pack.js       # 写入图标/版本，并剔除运行时无用文件
│  ├─ make-fixtures.js    # 生成自检用测试文件（PDF / 表单 / docx）
│  ├─ run-smoke.js        # 一次启动跑完整套自检（npm run smoke）
│  └─ audit-dead-code.js  # 冗余代码审计（未引用导出 / 文案 / 图标 / CSS）
├─ build/icon.ico     # 应用图标
└─ dist/              # 打包产物（安装包）
```

技术栈：Electron + pdf.js（渲染）+ pdf-lib（编辑）。中文文本按需内嵌系统黑体子集，不增加安装体积。

### 打包体积优化（v1.3.3）

安装后体积从 226 MB 降到 **217 MB**，安装包体积也同步下降。具体做法：

| 优化项 | 说明 | 收益 |
|---|---|---|
| 不再打包渲染层源码 | 运行时只加载 `dist/bundle.js`，`src/renderer/js/*.js` 是打包前的源码，不必随包分发 | asar 内减去约 200 KB 冗余源文件 |
| `charset: 'utf8'` | esbuild 默认会把中文转义成 `\uXXXX`（每汉字 6 字节），改为保留 UTF-8 原字符 | `bundle.js` 1.98 MB → 1.74 MB（-12%） |
| 剔除 Chrome 许可文本 | Electron 运行时里的 `LICENSES.chromium.html`（9 MB）与本应用功能无关，打包后由 `after-pack.js` 删除 | 安装后 -9 MB |
| 清理冗余代码 | 删除 12 个未被引用的导出函数、8 个未使用图标、18 条无用/重复的中英文案、1 条无用 CSS、若干重复行 | 保持功能不变 |

> 也可用 `node scripts/audit-dead-code.js` 随时复查是否又出现未引用的导出、文案、图标与 CSS。

> 说明：Electron 主程序（`PDFmini.exe` 约 173 MB）是运行时的固有体积，进一步压缩需要更换框架或裁剪 Chromium 组件（会影响渲染兼容性），因此未做处理。
