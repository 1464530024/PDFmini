# PDFmini

> 轻量 · 极速 · 极简 —— 面向 Windows 的 PDF 阅读与编辑桌面工具

基于 **Electron + pdf.js + pdf-lib** 的本地 PDF 工具。只保留日常真正用得上的阅读、批注、文字与图片编辑、页面整理、Word 转 PDF 等能力，去掉了 OCR、云端 AI、打印、主题切换等模块，因此在同类工具里体积小、启动快、全程无网络请求。

| 指标 | PDFmini | 说明 |
|---|---|---|
| 安装包 | 约 69.6 MB | 安装后约 217 MB |
| 打开速度 | 148 页文档约 0.6 秒 | 惰性解析，立即显示首屏，不等全部页面加载 |
| 后台请求 | 无 | 无订阅 / 评分 / 更新检查 |
| 界面语言 | 简体中文 / English | 安装时选择，软件内可随时切换 |

## 功能

### 阅读（浏览模式）

只读模式，专门用来「看 + 拿」：

- 本地 PDF、拖拽打开、最近记录、缩略图导航、书签目录
- 全文查找：命中高亮 + 结果列表直达
- **选中复制**：拖拽选中文字（自绘浅蓝高亮，一行一条、精确到字），`Ctrl+C` 复制；左键单击图片选中后也能复制
- 右键菜单：复制选中文字 / 复制此图片 / 复制本页文字 / 复制本页为图片

### 编辑（编辑模式）

免切工具，直接点：

- **点文字即编辑**：鼠标划过文字有高亮提示，点一下就地改，点空白处自动保存
- **点图片即编辑**：点 PDF 原生图片即选中，可拖动、四角缩放、替换、抹除
- **插入文字**：4 种字体（黑体 / 楷体 / 仿宋 / 等宽）+ 字号 + 颜色，浮动工具条即时调整
- **框选删除**：右键拖出方框 → 点「删除」确认，框内文字与图片一并抹除（像素级，不留残渣）
- **左键拖动平移页面**，与框选互不干扰

### 批注

高亮 / 下划线 / 删除线（选中文字自动标注，也可拖拽划区）、文本框、便签、墨迹手写、形状（矩形 / 椭圆 / 直线）、图章（预设 + 自定义）、签名（手写 / 导入图片）、橡皮擦。

### 页面与转换

- 页面管理：批量选择、删除、旋转、逐页导出、上下移动重排
- 插入空白页 / 从文件插入、合并 PDF、拆分 PDF（每 N 页或按页码范围）、裁剪页面
- 表单：填写 AcroForm（文本域 / 复选框 / 下拉框 / 单选组）
- 导出：文本 `.txt`、当前页图片 `.png`、图片转 PDF
- **Word 转 PDF**：内置轻量排版引擎离线转换 `.docx`

### 其它

多文档标签、中英文界面、文字缺失修复（针对缺字的异常 PDF 自动补画）。

完整说明见 **[docs/使用说明.md](docs/使用说明.md)**（含界面结构、快捷键、常见问题、与 PDFgear 的差异、全部已知限制）。

## 快速开始

### 使用安装包

1. 下载 `PDFmini-Setup-x.x.x-x64.exe`
2. 双击安装，选择安装语言（中文 / English）与安装位置（默认装到当前用户目录，**无需管理员权限**）
3. 可选创建桌面快捷方式，安装完成后自动启动

卸载：开始菜单 → PDFmini → 右键卸载，或安装目录下的 `Uninstall PDFmini.exe`。卸载会一并清除程序文件与个人配置。

### 从源码构建

需要 Node.js 18+。

```bash
npm install
npm run dev              # 开发模式运行（带开发者工具）
npm run dist             # 打包生成安装包（输出到 dist/）
```

`dev` / `start` / `dist` 都会自动先执行 `build:renderer`，因此克隆后无需手动构建。

## 开发命令

| 命令 | 作用 |
|---|---|
| `npm run dev` | 构建渲染层并以开发模式启动（自动打开 DevTools） |
| `npm run start` | 构建渲染层并正常启动 |
| `npm run build:renderer` | 仅构建渲染层（`esbuild` → `src/renderer/dist/`） |
| `npm run dist` | 打包生成 NSIS 安装包到 `dist/` |
| `npm run pack` | 只生成免安装目录 `dist/win-unpacked/` |
| `npm run smoke` | 跑完整套自检（20 个用例，**一次启动** Electron 跑完） |
| `npm run smoke -- sel` | 只跑名字里含 `sel` 的用例；`npm run smoke -- --list` 看全部用例 |
| `node scripts/audit-dead-code.js` | 冗余审计：未引用的导出 / 文案 / 图标 / CSS |

### 自检

```bash
npm run smoke
```

输出示例：

```
运行 20 个用例（单进程）…
OK   test                                 1867ms
OK   sel:fixtures/glyphs.pdf              6676ms
OK   marquee:fixtures/text.pdf            4987ms
...
20/20 通过，耗时 84.4s（1 次启动）
```

自检覆盖：选中高亮（逐字块 / 长URL / 乱序内容流 / 缩放）、浏览复制、编辑不换行、智能点击编辑、框选删除（含矢量点阵「删干净」断言）、原生图片编辑、插入文字、拖拽、链接、表单、图片删除、Word 转 PDF。

测试文件由 `scripts/make-fixtures.js` 自动生成到 `fixtures/`（需要 Windows 系统字体 `simhei.ttf`）。

也可以直接指定已安装/已打包的版本跑同一套自检：

```bash
SMOKE_EXE=D:/path/to/PDFmini.exe node scripts/run-smoke.js
```

## 项目结构

```
PDFmini/
├─ src/main/            # Electron 主进程（窗口、IPC、文件读写、剪贴板、关闭拦截）
├─ src/renderer/        # 界面（HTML / CSS / JS）
│  └─ js/
│     ├─ app.js         # 入口：工具栏、对话框、快捷键、自检入口
│     ├─ viewer.js      # 渲染核心：惰性解析、虚拟化渲染、选中高亮、缩放旋转
│     ├─ annotate.js    # 批注与编辑层：点文字编辑、框选删除、插入文字、图片编辑
│     ├─ flatten.js     # 保存时把批注写入 PDF（含中文字体子集嵌入）
│     ├─ ops.js         # 页面操作、合并拆分、裁剪、表单
│     ├─ io.js          # 打开 / 保存 / 导出 / 拖拽 / 导入
│     ├─ docx.js        # .docx → PDF 离线转换
│     ├─ textfix.js     # 文字缺失修复（康熙部首还原 + 缺字补画）
│     ├─ tabs.js        # 多文档会话管理
│     ├─ sidebar.js     # 缩略图、书签目录、搜索结果
│     ├─ i18n.js        # 中英文文案
│     └─ state.js       # 全局状态
├─ installer/lang.nsh   # 安装器扩展：把所选语言写入 lang.txt
├─ scripts/
│  ├─ build.js          # esbuild 打包（含体积优化）
│  ├─ after-pack.js     # 写入 exe 图标/版本信息，剔除运行时无用文件
│  ├─ make-fixtures.js  # 生成自检用测试文件（PDF / 表单 / docx / 矢量点阵）
│  ├─ run-smoke.js      # 一次启动跑完整套自检
│  └─ audit-dead-code.js# 冗余代码审计
├─ build/icon.ico       # 应用图标
└─ docs/使用说明.md      # 完整用户文档
```

## 技术栈

- **Electron 31** — 桌面外壳
- **pdf.js** — PDF 渲染 + 文本层
- **pdf-lib**（+ `@pdf-lib/fontkit`）— PDF 写入与编辑
- **esbuild** — 渲染层打包
- **electron-builder** — NSIS 安装包

两处值得说明的实现细节：

- **中文字体按需内嵌**：只有文档里出现非拉丁字符时才把系统黑体子集写进 PDF，纯英文文档体积不变。
- **虚拟化渲染**：只渲染可视区域附近的页面，滚动时自动卸载远处页面；148 页文档也能秒开。

## 已知限制

1. 旋转为「视图旋转」，不写入文件；永久旋转请用「页面管理」中的左转 / 右转。
2. 视图处于旋转状态时无法新增编辑内容（请先复位旋转）。
3. 「点文字即编辑」为覆盖式编辑，不修改原始文字对象。
4. 批注与编辑内容在保存时写入内容流，保存后不可再单独编辑。
5. 文字 / 图片编辑与「框选删除」采用「白底遮盖 + 覆盖式重写」：能修改、移动、替换、抹除，但**不改写 PDF 原始内容流**。删除后原文仍能被文本搜索到，需要彻底移除请用其它工具处理内容流。
6. 文字识别依赖已渲染出的文字层：滚动到尚未渲染的页面后，请稍等片刻再点击文字。
7. Word 转 PDF 为内置轻量排版引擎，复杂版式（浮动图片、艺术字、分栏等）会有损失；仅支持 `.docx`。
8. 页面管理缩略图最多显示前 300 页，操作仍对全部页面有效。
9. 图标为占位版本，替换 `build/icon.ico` 后重新打包即可更换。
10. 为精简体积，打包时会移除 Electron 运行时里的 `LICENSES.chromium.html`（Chromium/Electron 开源许可文本，程序不读取）。**如需对外分发，请自行补充相应许可声明**；想保留该文件，删掉 `scripts/after-pack.js` 中 `STRIP_FILES` 的对应项即可。
